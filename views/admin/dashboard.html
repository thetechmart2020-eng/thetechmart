Upload your price list (CSV)
Columns: brand, model, price, category, condition, storage, color, stock, imageUrl (optional). Category can be Phones, Accessories, Tablets, Audio, or anything else you want — leave blank and it defaults to Phones. Re-uploading updates matching rows instead of duplicating them.
Bulk photo upload
Select as many photos as you like at once. Name each file to match the device — e.g. apple-iphone-13-128gb-blue.jpg — and it's matched and added to that device's gallery automatically. Spacing, capitalization and dashes vs. underscores don't matter; if the brand+model alone is unique (e.g. samsung-s22-ultra.jpg) that's enough too.
